# Е ТВ · аниматик 3D бродкаст-пакета

Начальный этап анимации пакета Е ТВ, собранный в Blender: серые болванки, выставленный тайминг,
планы камеры и склейки. Это черновой проход, на котором проверяют ритм и композицию до
материалов, света и финального рендера.

| Ролик | Длительность | Планы |
|---|---|---|
| Заставка канала | 15 с · 450 кадров | ступени → подъём планки сверху → сканер сверху → макро у паза → финал сверху |
| «Вердикт» | 15 с · 450 кадров | лоток → макро вдоль шкалы → подъём печати сверху → удар → финал сверху |
| «Гаджетотека» | 15 с · 450 кадров | отсеки → курсор сверху → облёт геймпада → перелёт к пьедесталу → финал сверху |
| Отбивка | 5 с · 150 кадров | поток пикселей сверху → макро у знака → финал сверху |

Видео: 1280×720, 30 к/с, без звука. Тайминг, раскладка стола и движение камеры совпадают с
интерактивной версией пакета, поэтому аниматик можно класть прямо под финальный рендер.

## Что в кадре

- **Болванки.** Геометрия упрощена до плит, цилиндров и брусков. Стол нарезан тем же
  генератором, что и в веб-версии, поэтому плиты лежат на тех же местах.
- **Цвет только на событиях.** Всё серое, а фирменный циан #00D9FF и фиолетовый #7A35FF
  загораются в моменты из монтажного листа: нажатие кнопки, заливка знака, заряд печати, курсор.
- **Чистый кадр.** Без прожига и служебных подписей: в кадре только сцена.

## Файлы

- `etv_animatic.blend` — четыре сцены (`01_Заставка`, `02_Вердикт`, `03_Гаджетотека`, `04_Отбивка`).
  У каждого плана своя камера (`ID_SH01_…`), склейки сделаны маркерами с привязанной камерой.
  Точки монтажного листа отмечены маркерами `♦`. Ключи стоят только в ключевых позах, их можно
  двигать в Dope Sheet и Graph Editor. Шрифты упакованы в файл.
- `build_animatic.py` — собирает `.blend` с нуля.
- `render_animatic.py` — рендерит сцену Workbench-движком покадрово.
- `encode.sh` — склеивает кадры в mp4 и собирает общий шоурил.
- `video/` — готовые ролики аниматика.

## Как пересобрать

Нужен Blender 5.x (или модуль `bpy` 5.x: `pip install bpy`) и ffmpeg.

```bash
python build_animatic.py                         # или: blender -b -P build_animatic.py
python render_animatic.py 01_Заставка frames/01_Заставка
python render_animatic.py 02_Вердикт frames/02_Вердикт
python render_animatic.py 03_Гаджетотека frames/03_Гаджетотека
python render_animatic.py 04_Отбивка frames/04_Отбивка
./encode.sh frames video
```

В самом Blender ролик можно просто проиграть во вьюпорте: Solid-режим, цвет по объекту
(Viewport Shading → Color → Object), вид из активной камеры (Numpad 0).
